# Armonix **— sitio web del estudio**

Sitio estático de una sola página, listo para GitHub Pages.

## Archivos

- `index.html` — estructura y contenido
- `styles.css` — todos los estilos (tokens de diseño al inicio del archivo)
- `script.js` — menú móvil, reproductor de pistas (simulado) y formulario de contacto
